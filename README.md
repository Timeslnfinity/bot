# VC Stay Bot

A Discord bot that automatically joins one selected voice channel at startup.

## Required environment variables

Set these in your hosting provider's Environment Variables or Secrets page:

```env
DISCORD_TOKEN=your_real_discord_bot_token
VOICE_CHANNEL_ID=your_target_voice_channel_id
```

## Start command

```bash
npm start
```

## Security

Never upload `.env` or your real Discord bot token to GitHub.
